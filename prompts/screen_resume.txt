INSTRUCTIONS:
1. Extract the candidate's contact information (name, email, phone) from the resume.
2. Identify all skills mentioned in both the resume and job description.
3. Calculate a match score from 0 to 100 based on:
   - Skills overlap (40% weight)
   - Experience relevance and years (30% weight)
   - Education match (15% weight)
   - Overall fit and soft skills (15% weight)
4. Categorize skills into: matched (in both), missing (in JD but not resume), bonus (in resume but not JD).
5. Provide a recommendation: STRONG_MATCH (80-100), GOOD_MATCH (60-79), PARTIAL_MATCH (40-59), NO_MATCH (0-39).
6. Write a concise but thorough analysis paragraph.

Return ONLY valid JSON with this exact structure (no markdown, no explanation):
{
  "candidate": {
    "name": "string or null",
    "email": "string or null",
    "phone": "string or null"
  },
  "match_score": 0,
  "skills_match": {
    "matched": [],
    "missing": [],
    "bonus": []
  },
  "experience_summary": "string",
  "education_match": false,
  "recommendation": "NO_MATCH",
  "detailed_analysis": "string"
}
